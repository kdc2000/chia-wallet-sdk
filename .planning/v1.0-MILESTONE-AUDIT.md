## Cross-Phase Integration (sound — 0 gaps)

The integration check verified all six seams of the core flow — sender derives one-time PH from `spxch1…` address (P2) → send via `Action::send` + `SendDestination::SilentPayment` (P4/4.2) → signed bundle with `Relation::AssertConcurrent` multi-input binding and no SP-specific fingerprint (P4.1) → block farmed → `TweakData` extracted (P6 simulator helper / **P9 `tweak_data_from_block_spends` for real blocks, with Pass 2a same-puzzle-hash + Pass 2b iterative-Tarjan SCC grouping — not whole-block aggregation**) → `scan_from_tweaks` detects (P3) → recipient signs + spends. Reachable identically from Rust + napi + pyo3 + wasm.

Key seam findings (all INTACT):
1. **Single source of truth for block grouping** — `chia_sdk_driver::silent_payments::tweak_data_from_block_spends` (`block_tweak_data.rs:83`) is the only grouping impl; the simulator helper (`chia-sdk-test/.../tweak_data.rs:38`) and the binding facade (`chia-sdk-bindings/.../silent_payments.rs:453`) both delegate to it. No divergent fork.
2. **Relation threads into the multi-input path** (BRIDGE-03/04) — `Spends.prepare(deltas, Option<Relation>)` (`action_system.rs:177`) → driver `prepare` → `sp_finish_branch` binding gate (`spends.rs:603-606`): a ≥2-input SP send from Python/JS is drivable via `Relation.assert_concurrent()` and otherwise hits `SilentPaymentRequiresInputBinding`.
3. **Unified send surface** (4.2) — single `Action::send` + `SendDestination`; `From<Bytes32>` keeps non-SP callers compiling; **no dead parallel Phase-4 `silent_payment_send` action** (`actions/silent_payment_send.rs` is the `pub(crate)` apply-time handler).
4. **Phase 9.1 fixes preserve wiring** — ISSUE-1 facade guard returns a typed `Err` reachable across FFI; ISSUE-3 cfg_attr is lint-only; example builds under `--features chip-0057`.
5. **Example is a living integration test** — `examples/silent_payment.rs` runs single (Stages 1-5) + multi-input (Stages 6-9) over the public prelude surface; builds clean.
6. **Cross-language parity** — napi/pyo3/wasm each cover send→extract→scan→spend AND the multi-input path.
