```rust
pub fn prepare(
    mut self,
    ctx: &mut SpendContext,
    deltas: &Deltas,
    relation: Relation,
) -> Result<Spends<Finished>, DriverError> {
    // chip-0057 silent-payment derivation branch — runs FIRST so the
    // emitted `CreateCoin` conditions land on the parents'
    // `payment_assertions` before `emit_conditions` fires below. No-op
    // when no `Action::send` with a `SendDestination::SilentPayment`
    // destination has been applied.
    #[cfg(feature = "chip-0057")]
    if !self.silent_payments_pending.is_empty() {
        sp_finish_branch(ctx, &mut self, relation)?;
    }

    self.create_change(ctx, deltas)?;
    self.emit_conditions(ctx)?;
    self.emit_relation(relation);

    Ok(Spends {
        xch: self.xch,
        cats: self.cats,
        // ... rest verbatim — copy from current method ...
        _state: Finished,
    })
}
```

The `Ok(Spends { ... })` constructor's fields are unchanged — copy them verbatim from the existing method. `self` is already `mut` so no signature change required. The `#[cfg(feature = "chip-0057")]` gate on the new `if` block ensures the SP branch compiles away cleanly when chip-0057 is disabled.

**Ordering constraint (RESEARCH §1.3 line 347)**: The SP branch MUST run BEFORE `create_change` and `emit_conditions`. The `CreateCoin` conditions emitted by `sp_finish_branch` need to be on the parents' `payment_assertions` before `emit_conditions` consumes them.
