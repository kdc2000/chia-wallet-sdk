### bindy schema (from bindy-macro/src/lib.rs:35-86 — verified in RESEARCH)

A class with no `new` and no `fields` is structurally valid. Static methods land via:
```json
{
  "MethodName": {
    "type": "static",
    "args": { "arg_name": "TypeName", ... },
    "return": "ReturnType"
  }
}
```
The macro auto-discovers every `*.json` file in `bindings/` (bindy-macro/src/lib.rs:95-104) — just dropping `bindings/silent_payments.json` is enough to register it.

### bindy::Result return convention (every facade method)

All chia-sdk-bindings facade methods return `bindy::Result<T>`. The stub `probe_noop` returns `Result<u32>`.

### Required facade pattern for a unit struct

```rust
use bindy::Result;

#[derive(Clone)]
pub struct SilentPayments;

impl SilentPayments {
    pub fn probe_noop() -> Result<u32> {
        Ok(0)
    }
}
```

`#[derive(Clone)]` is REQUIRED — bindy's auto-generated wrapper struct requires the inner type to be Clone (per RESEARCH §"Established Patterns").
