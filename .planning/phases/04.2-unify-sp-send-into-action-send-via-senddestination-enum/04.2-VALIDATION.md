## Sampling Rate

- **After every task commit:** Run `cargo test --release -p chia-sdk-driver --features chip-0057 --lib -- <new_or_changed_test_name>` (~5-15s)
- **After every plan wave:** Run `cargo test --release -p chia-sdk-driver --all-features` + `cargo clippy -p chia-sdk-driver --all-features --all-targets -- -D warnings` + `cargo fmt --check` + 3 Phase 1 grep bans (`mod_by_group_order`, `^use sha2::`, `Sha256::digest` under `silent_payments/`) + 2 FINGERPRINT-01 grep gates from 04.1 + SEND-08 Privacy-warning count gate
- **Before `/gsd:verify-work` (phase gate):** Full workspace suite (~3-6 min) + `cargo machete` + all clippy permutations (`-p chia-sdk-driver` no-features, `-F chip-0057`, `--all-features`)
- **Max feedback latency:** ~15 seconds per task
