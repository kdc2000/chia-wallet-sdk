## Decisions Made

- **Tasks 1+2 atomic commit (4cd99543).** RESEARCH.md §"Atomic Commit Sequencing" Wave B authorizes this: the deletions are interdependent (deleting `Action::SilentPaymentSend` requires the deletion of the dispatch arms in the same commit, requires the module declaration removal in the same commit, requires the test relocation OR test deletion in the same commit — splitting risks transient-broken states of either compile or `Action` enum exhaustiveness). Combining Tasks 1+2 produces a clean green-at-every-commit boundary; the diff is still readable because most additions are colocated in `actions/send.rs::silent_payment_tests` (one block) and most deletions are colocated in the deleted file + 4 small touches.
- **Test destination: `actions/send.rs::silent_payment_tests`.** RESEARCH.md offered two destinations (this one + `action_system/spends.rs::silent_payment_finish_tests` for a split). Picked the simpler cohesion-focused option per the plan recommendation: one chip-0057-cfg-gated sibling sub-module, all 10 tests together (8 relocated + 2 NEW Wave 0). Rationale: close to the relocated apply-time chip-0057 SP arm in `SendAction::spend`, close to the relocated `memo_hint_guard` + `spend_silent_payment` helpers — one file owns the SendAction surface tests; no cross-file leak.
- **Privacy-warning rustdoc shape normalization.** Plan 02 added a rustdoc with the prefix `"Privacy warning (chip-0057):"` on `Spends::finish_with_keys`. The SEND-08 strict grep gate is `"Privacy warning:"` (with colon directly after the word) — the parenthetical-prefix form fails the strict grep. Rewritten to `"Privacy warning: under chip-0057,"` which preserves the chip-0057 disclaimer AND matches the strict grep. Final SEND-08 count: 10.
- **Broken intra-doc link inline-fix (Rule 1).** `cargo doc --workspace --all-features --no-deps` is one of Plan 03's phase-gate matrix items and fires `rustdoc::all -D` on the workspace. Plan 02's commit `b1f26930` introduced `[`SendDestination::SilentPayment`]` in `spends.rs:513`, which is unresolvable because `SendDestination` is not imported into `spends.rs`'s scope. Downgraded to plain code `` `SendDestination::SilentPayment` `` per the Plan 04.1-02 deviation 2 precedent (same root cause: cross-module rustdoc reference without an import). Zero new `#[allow]`.
- **Pre-existing chia-sdk-utils rustdoc error logged, not fixed.** `cargo doc -p chia-sdk-utils --all-features --no-deps` fires `rustdoc::private-intra-doc-links` on the `generate_label` reach-through wrapper introduced by Plan 03-04. Verified pre-existing on `main` via `git stash` + re-run. Out of Phase 04.2 scope (chia-sdk-utils source untouched by 04.2); logged to `deferred-items.md` for a future Phase 5 or maintenance plan to address.
