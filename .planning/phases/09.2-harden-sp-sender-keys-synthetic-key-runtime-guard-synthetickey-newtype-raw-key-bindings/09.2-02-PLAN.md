<objective>
Add `DriverError::SilentPaymentKeyNotSynthetic` and a runtime guard (GUARD-01) in `sp_finish_branch` that validates, for each non-ephemeral XCH input keyed by `ph = item.asset.p2_puzzle_hash()`, that `StandardArgs::curry_tree_hash(registered_pk) == ph` AND `registered_sk.public_key() == registered_pk`, returning the new error BEFORE any signing on mismatch.

Purpose: The universal backstop — the only guard that crosses the FFI boundary and the safety net for the newtype's `from_synthetic_unchecked` escape hatch and the bindings' raw-key path (Plan 03). Validates against the actual coin, so it accepts default AND custom-hidden synthetic keys and rejects raw keys, single-input included.
Output: One new error variant + the per-input guard + tests proving raw/`_unchecked`-wrong/single-input all fail typed before signing, and a correct key passes.
</objective>
